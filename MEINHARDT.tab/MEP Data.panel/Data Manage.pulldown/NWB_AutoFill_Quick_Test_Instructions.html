NWB AutoFill Quick Test

  1. Refresh pyRevit.
  2. Test both NWB_PARAMETERS AutoFill and NWB Dim AutoFill on a small mixed-discipline selection.
  3. For NWB_PARAMETERS AutoFill, choose the correct Arch room link if more than one architectural link is loaded.
  4. Check a few elements and confirm the written NWB values are correct.
  5. If something is wrong, send the latest log file from the tool logs folder and one screenshot of the affected element.

Logs already capture:

  • active view name and view ID
  • selected run options
  • selected and eligible element IDs
  • per-element category, family, type, level, and source details
  • linked-room department/building/site context for parameter autofill
  • parsed size, width, height, and diameter for dim autofill
